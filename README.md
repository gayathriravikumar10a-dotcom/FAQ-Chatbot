\# FAQ Chatbot with Retrieval-Augmented Generation (RAG)



\## Overview



A production-style FAQ chatbot built with semantic search and Gemini.



\## Features



\- Semantic retrieval using Sentence Transformers

\- Gemini-powered answer generation

\- Similarity threshold filtering

\- Hallucination prevention

\- Automated testing (15 tests)

\- Retrieval evaluation

\- Logging



\## Tech Stack



\- Python

\- Streamlit

\- Gemini API

\- Sentence Transformers

\- Scikit-learn

\- Pytest



\## Evaluation



\- Recall@3: 100%

\- MRR: 1.000

\- Precision: 100%

\- Recall: 100%

\- Accuracy: 100%



\## Run



```bash

streamlit run app.py

```
